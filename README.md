# Card Duel React

A React rewrite of the supplied card game. It uses the public Deck of Cards API to shuffle a deck and draw two cards per round.

## Run locally

```bash
npm install
npm run dev
```

Open the address printed by Vite (usually `http://localhost:5173`).

## Production build

```bash
npm run build
```

The static production files are generated in `dist/`.
